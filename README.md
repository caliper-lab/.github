# caliper-lab/.github

Org-wide defaults. GitHub uses these files in every `caliper-lab` repo that
doesn't have its own: PR template, `SECURITY.md`, issue templates.

This repo must stay **public** for the defaults to apply, so it never holds
secrets, internal hosts or customer names. Standards, CI and the audit playbook
live in the private `caliper-lab/platform-standards`.

Local folder is `dot-github`; the GitHub repo is named `.github`.
